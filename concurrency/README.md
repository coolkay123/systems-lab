# Concurrency and deadlocks

## Goals

- Distinguish processes, threads, and asynchronous tasks.
- Reproduce races rather than treating them as abstract warnings.
- Protect shared state with mutexes and condition variables.
- Identify the four necessary conditions for deadlock.
- Compare prevention, avoidance, detection, and recovery.
