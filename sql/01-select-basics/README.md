# Lab 01: SELECT basics

This lab builds an in-memory SQLite database and runs queries from `queries.sql`.
It requires only Python's standard library.

Before running it, read the queries and predict every result:

```sh
python3 sql/01-select-basics/run.py
```

Then edit `queries.sql` to answer:

1. Which category has the greatest average price?
2. How many products cost less than 20?
3. Which in-stock product is the most expensive?

Record your prediction and explanation by copying the experiment template.
