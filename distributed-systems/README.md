# Distributed systems

Begin this section after completing the SQL, concurrency, and networking
foundations. Those topics provide the mechanisms distributed systems build on.

## Planned progression

1. Single-node key-value server
2. RPC client and server
3. Primary-replica log replication
4. Failure injection: delay, loss, restart, and partition
5. Leader election
6. Simplified Raft

For every lab, identify the system's behavior when communication fails halfway
through an operation.
